## About me

Cybersecurity professional based in São Paulo, Brazil.

I work in a Security Operations Center, focusing on incident investigation, threat hunting, detection engineering, and security controls. My background also includes security architecture, risk assessment, and penetration testing.

Outside of work, I spend time studying offensive security, building Linux and network labs, and experimenting with artificial intelligence. I'm interested in how systems work, how they fail, and how they can be exploited or defended.
